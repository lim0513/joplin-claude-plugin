# joplin-tools: a Claude Code plugin marketplace

Contains one plugin, [`joplin`](plugins/joplin/README.md), which connects Claude Code to Joplin desktop or a Joplin Server (official or self-hosted).

```bash
/plugin marketplace add lim0513/joplin-claude-plugin
/plugin install joplin@joplin-tools
/joplin:setup
```
